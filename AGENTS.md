# Project Agent Notes

## Project-specific guidance

- Educational claims must define their metric and scope and link to a reviewable source, preferably a primary source. Keep unverified content explicitly marked as placeholder content.
- Ultracite is the quality entry point; Oxlint and Oxfmt own mechanical linting and formatting. Run `pnpm fix` after edits and `pnpm validate` before handoff.

## When Oxlint + Oxfmt cannot help

Manually verify domain and editorial correctness, source quality, user experience, accessibility, architecture, and edge cases.
